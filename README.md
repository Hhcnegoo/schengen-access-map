# Schengen Access Map

Reproducible data pipeline and bilingual (EN/RU) interactive site about
Schengen visas handled by consulates located in Armenia, Azerbaijan, Belarus,
Kazakhstan, Kyrgyzstan, Russia and Uzbekistan, 2019-2025.

Source: European Commission, "Short-stay visas issued by Schengen countries",
yearly "Visa statistics for consulates" workbooks.
