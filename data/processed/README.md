# Processed data

Generated by `python -m pipeline build` from the workbooks in `data/raw`.
Do not edit these files by hand: a test rebuilds them and compares the result
byte for byte.

Scope: consulates of the States listed in the source sheet
"Data for consulates", located in Armenia, Azerbaijan, Belarus, Kazakhstan,
Kyrgyzstan, Russia and Uzbekistan, 2019-2025.

## Files

| File | One row per |
| --- | --- |
| `consulate_year.csv` | year, country, Schengen State, consulate city (one source row) |
| `country_state_year.csv` | year, country, Schengen State |
| `country_year.csv` | year, country |
| `state_year.csv` | year, Schengen State (the seven countries combined) |
| `total_year.csv` | year (the seven countries combined) |
| `reporting_states.csv` | year, Schengen State present in the source sheet |
| `site_data.json` | the tables above plus display names, as read by the site |
| `validation_report.json` | results of the reconciliation checks |

## Columns

Identifiers

- `year` - reporting year of the source file.
- `country_iso3` - country where the consulate is located (ISO 3166-1 alpha-3).
- `schengen_state_iso2` - State that operates the consulate (ISO 3166-1 alpha-2).
- `consulate_id` - city of the consulate; `consulate_source_name` is the
  spelling in the source and `source_row` the row number in the source sheet.

Counts copied or summed from the source

- `uniform_applied` - "Uniform visas applied for".
- `uniform_issued` - "Total uniform visas issued (including MEV)".
- `mev_issued` - "Multiple entry uniform visas (MEVs) issued".
- `ltv_issued` - "Total LTVs issued" (visas with limited territorial validity).
- `uniform_not_issued` - "Uniform visas not issued".

Ratios recomputed from the counts in the same row

- `mev_share` = `mev_issued` / `uniform_issued`.
- `not_issued_rate` = `uniform_not_issued` /
  (`uniform_issued` + `ltv_issued` + `uniform_not_issued`).

Coverage counters (aggregated tables only)

- `consulate_entries` - number of source rows in the group.
- `consulates_with_applications` - rows with `uniform_applied` above zero.
- `states_listed`, `states_with_applications` - distinct Schengen States
  among those rows.
- `blank_<count column>` - number of rows in the group whose cell for that
  count is empty in the source.

`country_year.csv` only

- `not_issued_rate_source` - "Not issued rate for uniform visas" as printed
  for the country in the source sheet "Totals - third country". The 2019 file
  divides by applications; the 2020-2025 files divide by decisions, as
  `not_issued_rate` does for every year.

## Missing values

An empty cell means the source cell is empty. It is not zero. A sum skips
empty cells and is itself empty when every cell in the group is empty. A ratio
is empty when a cell it needs is empty or when its denominator is zero.

See `docs/METHODOLOGY.md` for sources, checks and known limitations.
